# Getting support

This is a free, open-source project, maintained by Mative on a best-effort basis. There is no support contract, and no
promise about how fast anyone answers.

| You want to                                                            | Go to                                                                                                                   |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Ask how something works, or talk about an idea that is not yet a plan  | [Discussions](https://github.com/mative-ai/adss/discussions)                                |
| Report a bug                                                           | A [bug report](https://github.com/mative-ai/adss/issues/new/choose), with scenario and seed |
| Propose a feature                                                      | A [feature request](https://github.com/mative-ai/adss/issues/new/choose)                    |
| Work on something from the help-wanted list                            | [HELP_WANTED.md](HELP_WANTED.md), then a "take an item" issue                                                           |
| Report a vulnerability                                                 | [SECURITY.md](SECURITY.md), privately and never in an issue                                                             |
| Get an access link to the hosted version, or talk to Mative about more | [Mative's contact page](https://www.mative.ai/en/contact)                                                               |

Before you ask, read the [README](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md), and search the open and the closed
issues: your question may already have an answer. Please be kind: see the [code of conduct](CODE_OF_CONDUCT.md).
